40) Difference Between Element Sum and digit sum of array : 2535

You are given a positive integer array nums.
The element sum is the sum of all the elements in nums.
The digit sum is the sum of all the digits (not necessarily distinct) that appear in nums.
Return the absolute difference between the element sum and digit sum of nums.
Note that the absolute difference between two integers x and y is defined as |x - y|.

Example 1:
Input: nums = [1,15,6,3]
Output: 9
Explanation: 
The element sum of nums is 1 + 15 + 6 + 3 = 25.
The digit sum of nums is 1 + 1 + 5 + 6 + 3 = 16.
The absolute difference between the element sum and digit sum is |25 - 16| = 9.

class Solution {
    public int differenceOfSum(int[] nums) {
     int n = nums.length;
     int elesum =0;
     int digisum =0;
     for(int i=0;i<n;i++){
              elesum = elesum + nums[i];
     }   
     for(int j=0;j<n;j++){
        if(nums[j]>9){
            int num = nums[j];
            while(num>0){
            digisum = digisum + num%10;
            num = num/10;
            }
        }
        else{
       digisum = digisum + nums[j];
        }
    }
    return Math.abs(digisum-elesum);
}
}

44) Find Pivot Index : 724
Example 1:
Input: nums = [1,7,3,6,5,6]
Output: 3
Explanation:
The pivot index is 3.
Left sum = nums[0] + nums[1] + nums[2] = 1 + 7 + 3 = 11
Right sum = nums[4] + nums[5] = 5 + 6 = 11

Example 2:
Input: nums = [1,2,3]
Output: -1
Explanation:
There is no index that satisfies the conditions in the problem statement.

Example 3:
Input: nums = [2,1,-1]
Output: 0
Explanation:
The pivot index is 0.
Left sum = 0 (no elements to the left of index 0)
Right sum = nums[1] + nums[2] = 1 + -1 = 0

optimal with space & not optimal with time coz nested for loop used :
class Solution {
    public int pivotIndex(int[] nums) {
        int n = nums.length;
        for(int i=0;i<n;i++){
            int lsum = 0;
            int rsum = 0;
            for(int j=0;j<i;j++){
                lsum = lsum +nums[j];
            }
            for(int k=n-1;k>=i+1;k--){
                rsum = rsum +nums[k]; 
            }
            if(lsum == rsum){
               return i;
            }
        }
        return -1;
    }
}

t.c : O(n^2) .s.c :O(1)

class Solution {
    public int[] separateDigits(int[] nums) {
        int n = nums.length;
        ArrayList <Integer> arr =  new ArrayList<>(); 
        for(int i=0;i<n;i++){
            if(nums[i]<9){
             arr.add(nums[i]);
            }
            else{
                int num = nums[i];
                ArrayList <Integer> rev = new ArrayList<>(); 
                while(num>0){
                    rev.add(num%10);
                    num = num/10;
                }
                int revlen = rev.size();
                while(revlen>0){
                    arr.add(rev.get(revlen-1));
                    revlen--;
                }
            }    
        }
            int result []= new int[arr.size()];
            for(int j=0;j<arr.size();j++){
                result[j] = arr.get(j);
            }
            return result;
    }
}

46) Transform Array by Parity : 3467
Input: nums = [4,3,2,1]
Output: [0,0,1,1]
Explanation:
Replace the even numbers (4 and 2) with 0 and the odd numbers (3 and 1) with 1. Now, nums = [0, 1, 0, 1].
After sorting nums in non-descending order, nums = [0, 0, 1, 1].

class Solution {
    public int[] transformArray(int[] nums) {
        int oddCount =0;
        int evenCount =0;
        for(int i=0;i<nums.length;i++){
            if(nums[i]%2==0){
                evenCount++;
            }
            else{
                oddCount++;
            }
        }
        int j=0;
        while(evenCount>0){
                nums[j]=0;
                evenCount--;
                j++;
        }
        while(oddCount>0){
            nums[j]=1;
            oddCount--;
            j++;
        }  
        
    return nums;
    }
}

t.c : O(n) , s.c :O(1)
