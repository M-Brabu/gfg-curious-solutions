1)Anagram :
s="nagaram" t="anagram" in both s & t  a-3 , n -1 , g-1, ,m-1 ,r-1 so thet are anagrams

brute :
class Solution {
    public boolean isAnagram(String s, String t) {
        if(s.length() != t.length()){
            return false;
        }
        HashMap  <Character,Integer> sm =  new HashMap<>();
        HashMap  <Character,Integer> tm =  new HashMap<>();
        for(int i=0;i<s.length();i++){
            sm.put(s.charAt(i),sm.getOrDefault(s.charAt(i),0)+1);
        }
        for(int j=0;j<t.length();j++){
            tm.put(t.charAt(j),tm.getOrDefault(t.charAt(j),0)+1);
        }
        return sm.equals(tm);     
    }
} 
t.c : O(n) , s.c : O(n)

optimal :  
works only for a-z:
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        int[] freq = new int[26];
        for (int i = 0; i < s.length(); i++) {
            freq[s.charAt(i) - 'a']++;
            freq[t.charAt(i) - 'a']--;
        }
        for (int count : freq) {
            if (count != 0) {
                return false;
            }
        }
        return true;
    }
}

optimal :
class Solution {
    public String largestOddNumber(String num) {
         for(int i =num.length()-1;i>=0;i++){
            if((num.charAt(i) - '0') % 2 != 0){
              return num.substring(0,i+1);
            }
         } 
             return "";   
    }
}

4) palindrome string : e.g : appa - rev - appa palindrome , boy - rev - yob not palindrome
Brute : 
class Solution {
    boolean isPalindrome(String s) {
        StringBuilder sb = new StringBuilder();
        int j=s.length()-1;
        for(int i=0;i<s.length();i++){
            sb.insert(i,s.charAt(j));
            j--;
        }
        String rev = new String(sb);
        if(rev.equals(s)){
            return true;
        }
        return false;
    }
}
t.c : O(n) , s.c : O(n)
optimal : 
class Solution {
    boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }

        return true;
    }
}
t.c : O(n) , s.c : O(1)
